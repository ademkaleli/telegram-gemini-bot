\# 🤖 AI Destekli 7/24 Telegram Asistan Botu



Bu proje, \*\*Python\*\*, \*\*pyTelegramBotAPI\*\* ve \*\*Google Gemini AI API\*\* entegrasyonuyla geliştirilmiş akıllı bir Telegram sohbet botudur.



\## 🚀 Özellikler

\* 🧠 \*\*Gemini AI Beyni:\*\* Sorulan her türlü soruya doğal dilde akıllı yanıtlar verir.

\* 🔒 \*\*Güvenli Mimarisi:\*\* API Anahtarları kod içine gömülmez, ortam değişkenlerinden okunur.

\* ☁️ \*\*7/24 Bulut Çalışması:\*\* Bilgisayardan bağımsız kesintisiz hizmet sunar.
